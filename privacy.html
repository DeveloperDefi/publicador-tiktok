Privacy Policy

Last updated: 20 September 2026

1. Scope

“Nathanael Estivalett Publicador” (the “Tool”) is used by exactly one person, its owner Nathanael Estivalett (the “Owner”). It has no other users, so it collects no data about anyone else.

2. What is collected

When the Owner authorises the Tool with TikTok, the Tool receives and stores:

  • the Owner's TikTok open_id and display name, used only to confirm that content is being posted to the correct profile;
  • an OAuth access token and refresh token, used only to call TikTok's Content Posting API.

Nothing else is requested or retained. The Tool does not read the Owner's videos, followers, messages, comments or analytics, and does not access any other TikTok account.

3. Where it is stored

These values are stored in a single configuration file on the Owner's personal computer. They are not uploaded to any server, database or third-party service, and are excluded from version control.

4. What is shared

Nothing. No data is sold, rented, shared with third parties, or used for advertising, profiling or analytics. The only network destination the Tool contacts is TikTok's own API.

5. Retention and deletion

Tokens are kept only while the Tool is in use. The Owner can delete the configuration file at any time, and can revoke the Tool's access from TikTok's own account settings, which invalidates the tokens immediately.

6. Children

The Tool is not directed at children and has no users other than its adult Owner.
